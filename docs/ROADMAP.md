# Roadmap

## v0.1.0 — Generic core and MGS4 profile

- define the data-driven game profile format;
- add `games.json` with the first verified profile;
- provide an experimental generic mode for unlisted games;
- validate 64-bit game executables and selected directories;
- verify the manual ReShade installation;
- obtain the pinned DLSS5-Feeder release;
- select external components without redistributing them;
- preserve selected filenames;
- save source paths locally;
- create a backup before installation;
- apply a selected profile or the generic layout;
- validate installed files and runtime logs;
- remove the setup and restore the backup;
- show the remaining manual ReShade steps;
- publish a Windows x64 executable for testing.

## First verified profile

- Metal Gear Solid 4;
- executable: `mgs4.exe`;
- working manual setup documented;
- DLSS5-Feeder v0.1.0 retained until a newer version is tested on the same game.

## Later

- document compatibility test requirements;
- add issue and pull request templates for game profiles;
- publish verified profiles contributed by the community;
- retest profiles when upstream components change.

A profile will not be described as supported until its complete flow has been tested.
